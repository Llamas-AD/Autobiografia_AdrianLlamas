# Mi Autobiografía en HTML5

Sitio web personal desarrollado como actividad académica para la asignatura de Desarrollo Web, con el objetivo de aplicar correctamente la estructura de un documento HTML5 y el uso de elementos semánticos.

🔗 **Ver sitio en vivo:** https://llamas-ad.github.io/Autobiografia_AdrianLlamas/

## 👤 Autor

**Adrian Felipe Llamas Quintero**
Estudiante de Ingeniería de Sistemas — Universidad de la Costa (CUC), Barranquilla, Colombia

## 📋 Descripción

Sitio web de una sola página (`index.html`) que presenta mi autobiografía, construido con HTML5 semántico y estilado con CSS puro (sin frameworks). Incluye una galería de fotos interactiva con efecto lightbox implementado en JavaScript vanilla.

## 🗂️ Estructura del contenido

- **Quién soy** — presentación personal
- **Mi historia** — infancia, familia y momentos importantes
- **Mi formación** — estudios y certificaciones
- **Mis intereses** — tecnología, videojuegos, fotografía y dibujo
- **Mi vida actual** — pasatiempos y proyectos personales
- **Una mirada especial** — testimonio de una persona cercana
- **Mi futuro** — metas y aspiraciones

## 🏷️ Elementos semánticos utilizados

`<header>` · `<nav>` · `<main>` · `<section>` · `<figure>` / `<figcaption>` · `<blockquote>` / `<cite>` · `<address>` · `<footer>` · `<dl>` / `<ul>` / `<ol>`

## 🛠️ Tecnologías

- HTML5
- CSS3 (variables CSS, diseño responsive)
- JavaScript vanilla (galería con efecto lightbox)

Clona el repositorio y abre `index.html` directamente en tu navegador:


No requiere instalación de dependencias ni servidor.
